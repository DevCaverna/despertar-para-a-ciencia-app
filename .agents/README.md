# Espaço de trabalho dos agentes

Este diretório reúne conhecimento, prompts e skills úteis aos agentes deste projeto.

| Diretório    | Finalidade                                     | Versionamento     |
| ------------ | ---------------------------------------------- | ----------------- |
| `memory/`    | Conhecimento reutilizável específico do app    | Versionado        |
| `prompts/`   | Prompts reutilizáveis, como revisão de código  | Versionado        |
| `skills/`    | Skills gerenciadas pelo ai-memory              | Versionado        |
| `artifacts/` | Planos, rascunhos, logs e arquivos temporários | Ignorado pelo Git |

As instruções do projeto ficam em [`../AGENTS.md`](../AGENTS.md). A seção delimitada pelos marcadores `ai-memory` nesse arquivo é gerenciada pelo ai-memory; não a edite manualmente.
